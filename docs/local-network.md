# 本地组网

通信面板展开“自动组网”，选择自动路由、链状或簇状，再启动。右侧配置面板可折叠，不改变节点选择或相机。

- 默认五节点使用固定错落坐标，深度 450～1700 m；实时模式默认位置不变。
- 自动路由使用最少跳数，其次总传播时延。链状严格按列表逐跳。簇状成员发给所属簇头，簇头之间选择可达路由到汇聚节点。
- 全网 TDMA 按 ID；路由顺序 TDMA 远端先发；两阶段 TDMA 先成员、后簇头，只适用于簇状。
- 32 字节总包长、2400 bit/s 有效速率，发送约 0.107 s。默认安全时隙 5.67 s，包含最大范围传播时间和保护间隔。原 PHY Bd 配置不转换为 bit/s。
- 前沿到达和完整接收是两个事件，完整接收之后才能中继；事件调度不依赖渲染帧率。
- 默认每四帧产生一批包：N1～N4 各一包。每帧产生一批可用于压力测试，但汇聚中继每帧只发一包，会积压并超时。
- 每节点 FIFO 上限 32，包寿命 120 仿真秒，TTL 16；无路由等待，接收失败丢弃。没有 ACK、重传、碰撞、数据融合或分布式簇头选举。
- 暂停冻结本地仿真时间，仍可操作相机；停止取消业务并保留统计；重置清空统计。修改组网配置前先停止。
- MAC/NET 输入保留手动配置，自动运行期间锁定；自动下一跳和时隙结果显示在组网面板。

验证：`node --test src/network.test.js src/propagation.test.js src/visualization.test.js`；`npm run build`。
