# 透明水域 · 水声节点传播演示

离线可运行的 Three.js 场景：直径 20 km、深度 4 km 的玻璃水域，AUV 节点可在水面或水下投放、巡航，并按物理时延与衰减发送 / 接收声波数据。

更完整的迭代说明见 [`工作记录.md`](./工作记录.md)。

## 尺度与物理

- 1 世界单位 = 1 米
- 水面直径 **20 km**（半径 10 km），水深 **4 km**
- 声速 `c = 1480 m/s`
- 三维距离 `d = √(Δx² + Δy² + Δz²)`，时延 `τ = d / c`
- 球面扩展 `20 log10(d)` + Thorp 吸收
- 超过最大作用距离，或接收级低于门限，则无法解调

## 离线运行

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173/`。打包后再离线预览：

```bash
npm run build
npm run preview
```

不要用 `file://` 直接打开 HTML。

## 操作

- 拖拽旋转，滚轮缩放，镜头可潜到水下
- 「点击投放」后在水面上单击；用「投放深度」决定水面或水下（0 到 -4000 m）
- 选中节点后填写 X / Y / Z，或按相对发射距离放置
- 「移动」里可开巡航：航速、航向、升沉、保持深度
- 最大作用距离可拖动或输入，最大 20 km
- 「发射声波」后，监听节点会显示波形与解码

## 接 Sealinx 仿真（可选）

```bash

./sim/run_live.sh
```

浏览器打开 http://localhost:5173/ 。停止用 `./sim/stop_live.sh`。
